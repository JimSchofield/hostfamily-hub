## Packages
framer-motion | Smooth page transitions and element animations
date-fns | Relative time formatting for posts (e.g., "2 hours ago")
react-hook-form | Form state management
@hookform/resolvers | Zod validation integration for forms
clsx | Utility for constructing className strings conditionally
tailwind-merge | Utility for merging tailwind classes

## Notes
The application requires a PostgreSQL backend to be provisioned.
`framer-motion`, `date-fns`, `react-hook-form`, `clsx`, and `tailwind-merge` are typically in the Replit base stack, but explicitly declaring them ensures they are available for the advanced UI interactions.
Images are assumed to be dynamically provided via URL inputs by the user (not uploaded to local storage).
